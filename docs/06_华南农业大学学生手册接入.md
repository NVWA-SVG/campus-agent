## 转换方式

现有Web PDF上传限制仍为100页。442页手册通过本地脚本提取成Markdown，再走原有 `KnowledgeBaseService.upload()`，不调整Web上传限制。

转换读取PDF目录书签，拼接同页折行的长规章名称，并保留PDF页码与可识别的印刷页码。正文先按320字符、48字符重叠预切分，每段使用独立Markdown标题，再进入现有分块器。这样不改变内置库的1200/120全局规则及原有Chunk ID。本次1130个手册片段的实际BGE输入（两遍标题＋正文）均未超512 tokens，最长432 tokens。

例如：`华南农业大学本科学生学分制实施细则｜PDF第74页·印刷第67页｜片段1`，引用时可以返回规章名和页码。PDF中的表格和图片没有重建为结构化表格/OCR；复杂表格应回看原PDF核对。

## 重现导入

在项目根目录运行，先从官方发布页下载原PDF到以下路径：

```powershell
$env:CAMPUS_EMBEDDING_PROVIDER = "sentence-transformers"
$env:CAMPUS_EMBEDDING_MODEL_CACHE_DIR = "$PWD\.campus_agent_data\models"
$env:CAMPUS_EMBEDDING_LOCAL_ONLY = "true"
.\.venv\Scripts\python.exe -m scripts.import_scau_handbook --pdf .campus_agent_data\source_documents\scau-student-handbook-2026.pdf --check-query "理论课多少学时计1学分？" --check-query "休学一般以几年为期？"
```

本地BGE模型需已缓存；缺少模型时服务会按现有逻辑降级，应查看输出的真实 `embedding_provider/vector_status`，不能仅以命令退出成功判定BGE已运行。重复导入相同转换结果会复用已有文档，不重复增加手册。若确实需要替换同名同版本的旧转换，可显式提供 `--replace-document-id <旧文档ID>`，脚本在新内容成功上传后删除指定旧导入。

完成后重启项目Web或开发版桌面端，在“知识库”查看手册及块数。已运行的其他进程不会自动感知脚本修改，需要重启或使用其重建入口。默认项目Web与开发版桌面端使用项目数据目录；打包桌面版默认使用 `%LOCALAPPDATA%\CampusAgent\knowledge`。若打包版需要使用本次导入，应在启动前将 `CAMPUS_KNOWLEDGE_DIR` 设置为项目 `.campus_agent_data\knowledge` 的绝对路径，或在其知识库页面上传本次生成的Markdown。

最后一题保留为质量改进点：需要区分首次向校内申诉与对复查结果向省教育主管部门申诉，补充相似条款的检索和答案核验。手册数据已接入，但不能据此宣称所有手册问题都能正确回答。这些检查属于少量检索/规则Agent冒烟，尚未运行RAGAS在线生成评委。

原有100条评测和对应分数只覆盖5份内置演示指南，`evaluate_rag.py/evaluate_ragas.py` 默认不会加载动态上传库。其旧分数不能当作这份手册或新全库的测评结果；后续应在手册来源页码基础上建立独立标注集，尤其覆盖跨条款、否定条件、相近期限和版本差异。
