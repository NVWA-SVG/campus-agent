CA Campus Agent API 完全本地的接口说明
无需外部 CDN OpenAPI JSON 返回工作台
HTTP API · v0.9.0

Campus Agent 接口

浏览器与 Agent 核心之间的本地接口。API Key 不属于任何请求字段，只能由后端环境变量读取。

GET /api/health

返回服务状态、DeepSeek 配置、知识库与向量缓存统计、校园业务 API 模式和当前页面会话使用的 CSRF Token，不返回任何 API Key、Token 或上游地址。

POST /api/chat

非流式兼容接口，返回回答、结构化引用、执行轨迹、指标和耗时。可选 filters 支持 metadata 过滤。

{
  "query": "周三有什么课程？",
  "session_id": "web-demo-1",
  "planner": "rule"
}
POST /api/chat/stream

网页默认使用的 POST SSE 接口。依次发送白名单化 trace 事件、完整 result 与 done；不会原样暴露 Graph State、文档正文或工具内部数据。

GET /api/history?session_id=web-demo-1

从 LangGraph SQLite Checkpoint 读取指定会话的用户与 Agent 消息，服务重启后仍保留。

DELETE /api/history?session_id=web-demo-1

删除指定 SQLite thread，其他会话不会受到影响。

GET /api/metrics?planner=deepseek

返回调用次数、Token、重试、延迟与规则降级指标。

GET /api/knowledge/documents

列出用户已上传资料及索引统计，不返回磁盘路径和文档正文。

POST /api/knowledge/documents?filename=guide.md&domain=policy&category=guide&version=2026.1

以原始请求体上传 Markdown、TXT 或 PDF，可登记 domain、category 和 version；解析成功后原子更新 Rule 与 DeepSeek 共用的本地索引。最大 10 MiB。

DELETE /api/knowledge/documents/{document_id}

永久删除指定上传资料，并在成功重建索引后提交删除。

POST /api/knowledge/rebuild

重新读取内置资料与上传资料，构造并原子替换 BM25 + Vector + RRF 混合索引快照。

写请求与网络边界

所有 POST 与 DELETE 接口都必须携带从 /api/health 取得的 X-CSRF-Token。规则模式不调用大模型；Mock 业务接口完全本地，Official 模式仅由 Python 后端访问固定的获授权 HTTPS 接口。Embedding 运行期只读取本地模型缓存，下载必须通过单独的准备命令显式执行。选择 DeepSeek 且后端配置有效 Key 时会请求模型 API。本页和工作台均不加载第三方脚本、字体或样式。
